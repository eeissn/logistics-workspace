### Отложено или требует продуктового решения

Эти направления не блокируют уже установленный релиз и не разрешают расширять права автоматически.

- **Google production:** по решению владельца исключён из выпуска. Остались рабочий доступ, защищённая установка ключа/config и согласованный режим без одновременных ручных структурных изменений листа либо другой механизм записи. Поле «Наименование» целиком в B; actor задаёт сервер. Учебную проверку не повторять как отсутствующую.
- **Новые напоминания задач/ЭТРН:** отложены владельцем после релиза; нужны события, сроки и канал. Существующие добровольные уведомления об ошибках синхронизации уже есть. Внешнее оповещение, когда домашний ПК полностью выключен, отдельно не настроено.
- **PDF-оригиналы:** решение владельца — пока без серверного хранения. Дизайн и синтетические измерения сохранены в [проектировании](PDF_ORIGINALS_STORAGE_DESIGN.md); это не незаконченный upload API. При возвращении к теме согласовать старые заявки/замены, измерить обезличенные реальные пары PDF, объём/WAL, сроки backup/доставки/восстановления и запас диска.
- **Справочник компаний для ЭТРН:** отдельная функция только для явно разрешённого владельца. Нужны решение о доступе, серверная изоляция/синхронизация, миграция и резервирование. Не путать со статусами ЭТРН и не открывать обоим аккаунтам.
- **Финансы:** настройка порога низкой маржи и достоверный учёт факта оплаты требуют решения. Не вводить «Не оплачено» по предположению или менять платёжные правила без согласования. Существующие расчёты/калькуляторы не переписывать заново.
- **Квартальный архив:** старое пожелание сверить с более поздним решением о единой истории. Автоматический перенос/удаление заявок не согласованы.
- **Telegram / HTML Widgets / бот оплат**, расширенное распознавание новых Excel-палитр — будущие отдельные этапы. Другие учебные проекты не смешивать с Workspace.
- **«Capi» и прежний «пункт №3»:** предмет не установлен; сохранить до появления контекста, не писать код по догадке.
- **Старые PR и источники:** не объединять/закрывать автоматически. Из чата «Сравнение ИИ агентов» была доступна только часть ранней истории; полный аудит всего экспорта не заявлен.

### Правила продолжения

- Выбирать один открытый пункт этой карты; код, тесты, выпуск и пользовательскую приёмку отмечать раздельно с SHA/доказательством.
- Перед новым слиянием или выпуском сверять CI конкретного SHA. Успех выпущенного `1de5798` не доказывает CI нового коммита документации или журнала.
- Только синтетические данные в тестах/артефактах. Базы, ключи, реальные документы и сведения водителей не публиковать. Обнаруженный локальный `test-restore.sqlite3` не удалять без решения владельца.
- Последняя проверка npm audit 19.11: 0 известных уязвимостей, прежний GHSA-fc5q-39xc-vjpf был отозван. Это датированное доказательство, не гарантия для будущих зависимостей; старую отметку «4 high/no patch» не считать текущим риском без новой проверки.
- Production/SSH/учётные записи/база/резервные копии, main и слияния — только в отдельно согласованных пределах. Текущая задача — сверка документов, без изменений VPS.
