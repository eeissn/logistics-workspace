# Дизайн-система Sputnik

Sputnik — светлая тема для новых профилей. Violet и Sand сохраняют свои идентификаторы, палитры, виды реестра и пользовательские акценты. Профиль с сохранённым оформлением продолжает открываться в выбранной теме.

| Область | Правило |
| --- | --- |
| Цвет | Белая рабочая поверхность, прохладная серая навигация, графитовый акцент. Токены `--paper`, `--surface`, `--ink`, `--muted`, `--line`, `--accent`. Пользовательский цвет дополняет текст статуса. |
| Типографика | Системный шрифт Windows и iOS. Заголовок страницы 26–34 px, заголовок карточки 18–19 px, рабочий текст 13–15 px. Номера и время сканируются по строкам, интервалы используют табличные цифры. |
| Сетка | Левая панель 184 px до перехода в мобильное меню на 850 px. Команды реестра в двух колонках на узких экранах. Вся страница остаётся в ширине окна. Канбан и широкая таблица прокручиваются внутри своей области. |
| Отступы | Базовый шаг 4 px. Зазоры между контролами 6–10 px, внутри рабочих областей 12–16 px. Скругление контролов 8 px. Тени помогают различить перекрывающие слои. |
| Контролы | Первичное действие залито акцентом. Вторичные используют нейтральную поверхность. Сохраняем нативное управление select, датами и формами. У частых действий на телефоне цель 44 CSS px. |
| Детали | Номер, маршрут, статус и ход рейса, окна, участники, ЭТРН, дополнительные сведения. Контакты и редактирование остаются в контексте заявки. |
| Состояния | Ожидание отмечается во время запроса, подтверждение — по ответу API, ошибки содержат следующее действие. Текст и положение дополняют цвет. Для ошибочного сохранения форма сохраняет ввод. |
| Движение | Переходы короткие, обычно 150–190 мс, привязаны к действию. Настройка уменьшения движения отключает необязательные эффекты. Фоновые обновления реестра без анимации. |
| Доступность | Видимый фокус, семантические кнопки и заголовки, доступные имена полей и диалогов, объявления состояния. Цель WCAG 2.2 AA, включая контраст текста, видимость фокуса и reflow. |
