# Дизайн-система Sputnik

Sputnik — светлая тема для новых профилей. Violet и Sand сохраняют свои идентификаторы, палитры, виды реестра и пользовательские акценты. Профиль с сохранённым оформлением продолжает открываться в выбранной теме.

| Область | Правило |
| --- | --- |
| Цвет | Белая рабочая поверхность, прохладная серая навигация, графитовый акцент. Токены `--paper`, `--surface`, `--ink`, `--muted`, `--line`, `--accent`. Пользовательский цвет дополняет текст статуса. |
| Типографика | Системный шрифт Windows и iOS. Заголовок страницы 26–34 px, заголовок карточки 18–19 px, рабочий текст 13–15 px. Номера и время сканируются по строкам, интервалы используют табличные цифры. |
| Сетка | Левая панель 218 px на широком экране, 200 px на промежуточном до мобильного меню на 850 px. На телефоне остаётся нижняя навигация, поиск и фильтры не выходят за ширину окна. Канбан и широкая таблица прокручиваются внутри своей области. |
| Отступы | Базовый шаг 4 px. Зазоры между контролами 6–10 px, внутри рабочих областей 12–16 px. Скругление контролов 8 px. Тени помогают различить перекрывающие слои. |
| Контролы | Первичное действие залито акцентом. Вторичные используют нейтральную поверхность. Сохраняем нативное управление select, датами и формами. У частых действий на телефоне цель 44 CSS px. |
| Детали | Номер, маршрут, статус и ход рейса, окна, участники, ЭТРН, дополнительные сведения. Контакты и редактирование остаются в контексте заявки. |
| Состояния | Ожидание отмечается во время запроса, подтверждение — по ответу API, ошибки содержат следующее действие. Текст и положение дополняют цвет. Для ошибочного сохранения форма сохраняет ввод. |
| Движение | Переходы короткие, обычно 150–190 мс, привязаны к действию. Настройка уменьшения движения отключает необязательные эффекты. Фоновые обновления реестра без анимации. |
| Доступность | Видимый фокус, семантические кнопки и заголовки, доступные имена полей и диалогов, объявления состояния. Цель WCAG 2.2 AA, включая контраст текста, видимость фокуса и reflow. |

## Приёмка оформления 17.11.2026

Уточнённые ориентиры: Apple — один различимый первичный CTA, последовательное расположение инструментов и читаемые размеры касания; Attio — постоянная навигация по объектам и быстрые действия в контексте записи; Linear — компактные виды/фильтры и управляемая плотность. Из оригинальных продуктов не копируются графика, изображения или исходный код.

| Компонент | Приёмочный критерий |
| --- | --- |
| Заголовок и новая заявка | Основная кнопка рядом с названием раздела, видна на 393px и широком экране; не теряется после выбора фильтра. |
| Вторичные действия | Поиск и фильтры с общим ритмом; на мобильном нет выхода за экран или перекрытия нижней панели. |
| Навигация | Постоянная на desktop; предсказуемое раскрытие на mobile, видимый выбранный быстрый фильтр и сброс. |
| Типографика | Текст основных инструментов не меньше 13.5px на desktop, новый CTA не меньше 12.5px на телефоне; номера и суммы используют табличные цифры. |
| Карточка | Содержимое прокручивается независимо, кнопки читаются, контакты разделены, два документа различимы; на телефоне действия доступны над safe area. |
| Доступность | Проверка фокуса клавиатуры, имён кнопок, WebKit/Chromium, pref-reduced-motion, 4 видов и 4 тем. |
| Безопасность | Ни одна CSS-правка не меняет владельца заявки, данные SQLite, ЭТРН, документы или резервирование. |

Артефакты CI `workspace-visual-qa` содержат синтетические снимки для ручной проверки перед обновлением VPS. Автоматические тесты проверяют границы и поведение, но не доказывают абсолютное визуальное соответствие Apple или Attio.
