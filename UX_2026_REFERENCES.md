# UI/UX 2.0 · визуальные ориентиры и критерии приёмки

Решение владельца 17.11.2026: применять направления из утверждённой таблицы **Attio / Linear / Steep / Raycast + Linear / Rill Browser / Kombai Gallery**. Изучаются принципы, **не** копируются графика, логотипы и интерфейсы других продуктов. Сохраняются сценарии Logistics Workspace, три существующие темы, четыре вида реестра и полный контроль данных на сервере.

| Источник | Применение | Текущее воплощение в feature-ветке |
|---|---|---|
| **Attio** | Плотный реестр, фильтры, боковая карточка | Существующий табличный реестр и список + детали; выделение выбранной заявки и закреплённая панель для desktop без перехода на другую страницу. |
| **Linear** | Статусы, микроотклики, компактные контекстные действия | Цветовые полосы статуса, видимые фокус/hover и сглаженные переходы с уважением настройки reduced motion. Статусы рейса и ЭТРН **не объединяются**. |
| **Steep** | Показатели, финансовая сводка, группировка | Три компактных блока «Период», «Заявки», «Маржа» по **существующему** `monthSnapshot`; никакой новой методики маржи или финансовых правил. История по месяцам уже работает. |
| **Raycast + Linear** | Быстрые команды и мобильная навигация | Панель быстрого доступа на телефоне; Ctrl/⌘+K открывает палитру, «/» фокусирует поиск в реестре. Обычная навигация остаётся доступной. |
| **Rill Browser** | Объединение инструментов и контекста | Палитра действий для поиска, истории, формы заявки, двух PDF, Excel, отчёта, видов и настроек; без доступа к чужим аккаунтам и скрытых записей на сервере. |
| **Kombai Gallery** | Точечная полировка форм и диалогов | Чёткие заголовки, отступы, видимый фокус, удобные цели касания, общее оформление модальных окон; не переделывать смысл полей. |

## Поведение и безопасность

- Палитра `src/command-palette.mjs` **только вызывает существующие действия UI**. В ней нет произвольных команд, отправки данных или массового изменения ЭТРН. Для гостя без сеанса команда не открывается.
- Отдельная публичная `/ux-preview/` собирается с `VITE_DEMO=true`, `VITE_UX_PREVIEW=true`: синтетические записи и собственные ключи localStorage. Не обращается к production API, не содержит реальные номера и документы.
- Изменения `src/style.css` сохраняют Violet, Sand и Sputnik и режимы таблица/компактный список/канбан/список + детали. На iPhone нижняя панель не скрывает область ввода, учитывает safe area. Оригинальные меню и экспорт сохранены.
- `ROADMAP.md` и `AGENT_STATE.md` должны отличать реализацию, зелёный CI, публикацию Pages и физическую приёмку Windows/iPhone.

## Критерии приёмки

- [x] Реализованы команды поиска, истории, новой заявки, Excel/PDF, финансов и видов — без изменения API, SQLite или производственных данных.
- [x] Реализована компактная аналитика без замены финансовых расчётов.
- [x] Добавлены адаптивная мобильная навигация, закреплённые детали и визуальные состояния для существующих статусов.
- [ ] Проверен **полный CI последнего SHA** и сквозные Chromium/WebKit после изменений.
- [ ] Подтверждены desktop Zen/Windows и настоящий iPhone Safari в трёх темах и четырёх режимах, отсутствие перекрытий, фокус, сохранение и две учётные записи.
- [ ] После обратной связи владельца согласован точный SHA для объединённого рабочего релиза с резервной копией и откатом; до этого main/VPS не менять.
