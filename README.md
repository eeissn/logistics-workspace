# Logistics Workspace

Отдельный адаптивный прототип для браузеров на Windows и iPhone. Реестр поддерживает создание и редактирование заявки, поиск, фильтр ЭТРН и импорт пары текстовых PDF Логистора. Перед сохранением импортированная заявка открывается на проверку.

В импорте у каждого PDF свой выбор файла. После распознавания можно сразу сохранить сводку или открыть редактор. В реестре доступны телефоны перевозчика, водителя и точек, статус рейса и отдельное окно ЭТРН.

Разделы «Загрузка сегодня» и «Выгрузка сегодня» используют московскую календарную дату и учитывают диапазоны. Выгруженные рейсы с закрытой ЭТРН и срывы видны в архиве внизу. Статус можно изменить и после архивации.

«Импорт Excel» читает лист «Ноябрь» за 2026 год. Он добавляет отсутствующие номера и сохраняет значение столбца «Маржа». Галочки «Заказ-заявка» и «ЭТРН» отмечают создание документов. Завершение рейса и подписи подтверждаются отдельно. «Отчёт по марже» выбирает календарный месяц по дате заявки, учитывает архив, исключает срывы и сохраняется в PDF через печать браузера.

## Локальный запуск

Инструкции по запуску FastAPI, созданию двух аккаунтов и локальной проверке находятся в [backend/README.md](backend/README.md). Для автономного демо используйте `VITE_DEMO=true npm run dev`. Демо хранит заявки в браузере.

`npm run build` собирает сайт в `dist/`. PDF.js читает документы в браузере. Сервер сохраняет извлечённые поля заявки, включая данные водителя. Исходные PDF не загружаются на сервер. Кнопка «Данные водителя» открывает текст для ручного копирования. Прототип поддерживает текстовые PDF Логистора.

## Правила

- Пара сверяется по номеру и цепочке сторон. Ставки берутся из соответствующих PDF.
- Окна перевозчика имеют приоритет. Расхождения с заказчиком видны в карточке. Если в PDF перевозчика нет окна, используется окно заказчика с указанием источника.
- Телефоны участников и точек доступны в карточке. Пустые контакты не додумываются.
- Учитываются сроки оплаты перевозчику по оригиналам и ЭДО. Календарная дата платежа не вычисляется автоматически.
- ЭТРН отслеживает создание, номер, четыре подписи и ручное завершение. Это внутренний учёт статуса без интеграции с оператором ЭТРН.
- Модель расчёта маржи перенесена из [eeissn/margin-calculator](https://github.com/eeissn/margin-calculator/blob/main/index.html), версия файла `49c79991646fce7fed84061e397e07d8f6eb6df3`.

Отложенные улучшения перечислены в [ROADMAP.md](ROADMAP.md).
